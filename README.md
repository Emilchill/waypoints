# Waypoints for Cinnabar

**⬇️ Download:** [`waypoints.wasm`](https://github.com/Emilchill/waypoints/raw/main/download/waypoints.wasm) (Cinnabar v0.1.31 or newer). Import it in **Settings → Mods → Import mod...**

Waypoints for Minecraft Bedrock on Cinnabar, made by Emil Chill and Claude AI.

Needs a Cinnabar build with the new mod API (October 25, 2026 or later; SDK commit 613d078).

- **Death Point**: when you die, a red ☠ marks the spot (in the dimension where you died). It is
  removed when you walk back to it (can be turned off).
- **Waypoints**: press **P** to drop one where you stand, or make one in the menu and type its
  own name. Each one has a name, one of the 16
  Minecraft colors and an icon: the first two letters in a box (the default) or
  one of 20 symbols. A waypoint can be hidden without deleting it.
- **Nether ↔ Overworld copy**: one click copies a waypoint to the other dimension at the matching
  place (coordinates ÷ 8 or × 8).
- **Per world and per dimension**: each server or world keeps its own list, and the Overworld,
  Nether and End are kept apart: you only see the waypoints of the dimension you are in.
- **Seen from any distance**: every waypoint's box (icon or initials), name and distance always
  face you and show through walls, at the same size on screen however far away it is.
  Letters and icons are smooth vector shapes (from DejaVu Sans), not pixels. Showing them
  through blocks needs the **Through walls** permission: accept it when Cinnabar asks.
- **Beams**: a colored beam on the nearest 12 waypoints within 75 blocks (farther ones switch
  their beam off to save work; the badge still shows), optionally visible through walls.

Menu: open it from **Mods Core** (F10, then click Waypoints), or set your own key in Settings (empty by default). While the menu is open it claims the typing keys, so other mods
(loaded after this one) do not react while you type a name. The P key is rebindable too. The menu is its
own screen (custom JSON-UI, generated by `tools/gen_surface.py`):

- **List**: every waypoint of this dimension as a row with its colored tile and icon, name,
  distance and coordinates; sort, filter by set, pages. Click a row to edit it.
- **New Waypoint** (separate from editing): click the name box and type the name (Enter to
  finish), then pick the set, color (16 swatches) and icon
  (21 tiles) with a live preview, then **Create here**.
- **Edit Waypoint**: rename by typing, the same choices plus hide, move here, nudge X/Y/Z, copy to Nether or
  Overworld, keep (death point) and delete (asks twice).
- **Settings**: switches and steppers for everything, and the keys.

In the world, each waypoint shows a glowing beacon beam with a gem on top and a mark on the
floor, plus a badge with its icon, name and distance. The badge is drawn by the mod itself (its own
vector font, `tools/gen_font.py`), so it shows even when another mod owns the HUD.

Up to 120 saved waypoints (the death point always fits). Everything is stored in the mod's settings file in a compact format
that the mod reads a little each frame, to stay under the fuel limit.

Files from v1.0 are converted automatically.

Build: `python scripts/build-mod.py` → `dist/waypoints.wasm`.


## Phones and tablets (Android)

On touch controls this mod adds a **+ WP** button that adds a waypoint where you stand. Move it with the touch layout editor.
